New space Press Shift + N
New collection Press Shift + C when viewing a space
New item Press Shift + I when viewing a collection
Paste item Press Ctrl + V to paste a link from clipboard as a new item inside a collection
Search tag in space Ctrl + Click a tag inside a collection or Click a tag inside space-wide search results
Search tag in collection Click a tag inside a collection or Ctrl + Click a tag inside space-wide search results
Change tag color Click a tag while editing an item (only works if the tag is not added on another item)
